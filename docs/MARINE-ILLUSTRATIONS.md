# Marine illustrations

Original SVG drawings use normalized primitives and a representative template. The library covers compact, standard, touring, performance and fishing PWCs, pontoon, tritoon, jet and fishing pontoons, jet and tower jet boats, bowrider, center console, wake, bass, aluminum and cruiser profiles. Some families appear in the gallery as synthetic geometry until a representative real variant has been verified.

A common inches-to-pixels scale uses verified overall length in side views and verified overall length plus overall beam in top views. Deck width is excluded as a beam substitute. Unknown dimensions appear with an explicit schematic label. Hull contours, windshields, rails, seats and heights are illustrative. The adult, pickup and SUV are generic examples with labeled nominal dimensions. Use consistent row and overlay scales for comparisons.

Garage, storage unit and slip views compare a measured rectangular space to hull or manually entered stored dimensions. Key openings and clearance are optional for preliminary checks and are required for a complete storage assessment. Turns, projections, obstructions and actual trailer geometry require direct measurement.

To add a family, define its template key and normalized paths, map a verified category or configuration rule, then inspect both styles, views, overlay, and compact cards at desktop and mobile widths in the local gallery. Preserve source identity and keep unsupported features out of variant-specific labels.
