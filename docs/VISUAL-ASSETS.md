# Marine visual assets

Generated with the built-in ImageGen tool for BoatCostGuide. The production filenames are under [public/marine](../public/marine), and include 420px and 720px portrait hero crops, with a separate updated [social image](../public/social.png). All are generic visual illustrations. No actual model photography or manufacturer assets were used.

| File                  | Intent                                                                                               |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| `hero.webp`           | White recreational center console with open ocean, dark left foreground and a golden-hour coastline. |
| `pontoon.webp`        | Aluminum pontoon and black bimini on a calm lake.                                                    |

| `cabin-cruiser.webp`  | Enclosed forward cabin and quiet coastal bay.                                                        |
| `bass.webp`           | Low-profile freshwater fishing hull with casting decks.                                              |

Hero prompt was for a 3:2 premium marine campaign photo from a high drone at golden hour, with a generic white 28-foot center console entirely on the right, a wake stretching left across navy Atlantic water, a low coastline, warm light, realistic hull/water and no logos, text or branding. Category prompt requested an equal eight-tile four-column by two-row photographic contact sheet, with the subjects above in filename order, consistent three-quarter framing, clean daylight, blue-green water, complete boats and no text, brands or gutters. Tiles were extracted individually and cropped to show the vessels.

The hero source is 1536×1024 WebP and approximately 298 KiB. Category crops are 378×245 WebP, approximately 24–36 KiB each, with explicit responsive breakpoints and lazy loading. The hero uses a reserved layout and one high-priority responsive image request. Social uses a 1200×630 crop and the existing Open Graph route. Accessible adjacent text labels each category; decorative images use empty alt text. Category artwork in prototype record cards is visibly identified as illustrative.

Future model assets need an explicit license from the OEM or rightsholder covering public, commercial, indexable page display, CDN hosting and responsive image derivatives. Record original URL, asset ID, exact boat/configuration, required credit, scope, retrieval date and expiration. The owner only needs to obtain images for the approved real-model pilot.
