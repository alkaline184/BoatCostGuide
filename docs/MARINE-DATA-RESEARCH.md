## Live probe log

Read-only HTTPS GET requests without credentials were issued on the review date. This verifies access behavior and public schemas, never a successful authenticated catalog import.

| Request                                           | Observed result                                                                                                              |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `vehdb.com/openapi.json`                          | HTTP 200 JSON, OpenAPI 3.1, roughly 72 KB. Lists versioned boat paths and dashboard bearer authentication.                   |
| `api.vehdb.com/v1/boats?per_page=1`               | HTTP 401 JSON. No boat records returned.                                                                                     |
| `api.theboatdb.com/v1/boats`                      | HTTP 401 JSON, `MISSING_API_KEY`.                                                                                            |
| `api.marinebase.dev/openapi.json`                 | HTTP 200 JSON, OpenAPI 3.1.                                                                                                  |
| `api.marinebase.dev/v1/specs/fields`              | HTTP 200 JSON with version, sections, fields, total and units. It is a field dictionary.                                     |
| `api.marinebase.dev/v1/sailboats/search?limit=1`  | HTTP 401 JSON requiring a bearer token.                                                                                      |
| `api.boats.com/docs/services/details?s=inventory` | HTTP 200 HTML documentation.                                                                                                 |
| `api.boats.com/inventory/search?rows=1`           | HTTP 200 JSON with an `error` envelope and no authenticated inventory.                                                       |
| USCG MIC and recalls public pages                 | HTTP 200 HTML for both. Recall HTML exposes dated campaign IDs and detail links. MIC exposes lookup and no active bulk link. |

Price Digests, Marine CONNECT and Boatpedia were evaluated from public product information without running undocumented or gated endpoints. No subscription, registration, license acceptance or restricted data extraction was performed.

## Recommendation and owner actions

1. Start with 12–20 owner-approved, manually verified US variants in two or three categories. Ask OEMs for a written commercial/editorial usage grant covering public indexing, image file hosting, thumbnails, responsive derivatives, credits, expiry and takedown. Request a year-specific official spec sheet and media asset IDs for each variant. [Manufacturer review](MANUFACTURER-DATA.md)
2. Contact [VehDB sales](https://vehdb.com/contact) and request a scoped evaluation token, nine-brand coverage export or provider-run counts, field dictionary, and written rights for public HTML, search crawling, static storage and termination. This is the first powerboat taxonomy trial. Cross-check exact model year and engine against the OEM.
3. Ask [TheBoatDB](https://theboatdb.com/pricing) for a sandbox and written confirmation covering the proposed editorial catalog and licensed images, including the distinction between display caches and static dataset storage. Compare null rates and coverage against VehDB before selecting a supplier. Trial pricing requires owner authorization.
4. Ask [USCG Boating Safety](https://uscgboating.org/content/contact-us.php) for the supported MIC and recall access method, redistribution terms, refresh cadence and campaign matching fields. Begin with official citations and manual campaign review.
5. If pricing adds enough utility later, get separate quotes from Price Digests and J.D. Power for commercial web valuations. For live listings, contact Boats Group and require deletion/unpublish SLA and an approved listing-photo license. Defer Marinebase until sailboat coverage is needed, and revisit Boatpedia after public access resumes.
6. Authorize a trial or fee only after written usage terms, target coverage and cost are clear. Supply evaluation credentials through a secure secret store, scoped to staging. Keep actual model imagery absent until a specific asset grant is recorded. Phase 3A’s generic category art is already available for editorial use.
